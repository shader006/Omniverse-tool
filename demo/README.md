# Omniverse Header UI Demo (React Native Style)

This folder contains the official Header UI component adapted from [reactnative.dev](https://reactnative.dev/) with 100% exact dimensions, typography, colors, and layout.

## Features
- **Faithful React Native Navbar**: Exact Docusaurus navigation bar layout with mobile toggle, brand logo, Docs dropdown, feature navigation, GitHub link, and search bar.
- **Light & Dark Theme Switcher**: Interactive button toggling CSS variables and themed assets (`themedComponent--light` / `themedComponent--dark`).
- **Production Asset Integration**: Official Meta Optimistic Display webfonts and SVG branding.
- **English Localization**: Tailored for the Omniverse Multi-Media & AI processing platform.

## Quickstart
```bash
# Start development preview
npm run dev

# Production build
npm run build
```
